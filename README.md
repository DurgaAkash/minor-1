# SmartRoute AI
### AI-Based Smart Rural Transportation Planning and Optimization System

A beginner-friendly frontend prototype for exploring rural passenger demand, route suggestions, bus schedules, and passenger check-ins.

## Features
- Dashboard with passenger, route, and bus summary cards.
- Passenger check-in form with origin, destination, travel date, time, and passenger count.
- Route planner that generates route suggestions from the entered locations.
- Demand analysis based on saved check-ins.
- Schedule recommendations based on passenger demand.
- Browser localStorage persistence; no backend or API key required.

## Run in VS Code
1. Download or clone this repository.
2. Open the `minor-1` folder in VS Code.
3. Open `index.html` in a browser, or use the **Live Server** extension.
4. Add passenger check-ins and test the dashboard and route planner.

## Note
This is a frontend demonstration. The route suggestions and demand-based schedule recommendations use transparent rule-based demo logic and sample data. They are not live bus tracking or a trained machine-learning model.
