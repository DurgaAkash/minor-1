# SmartRoute AI
## AI-Based Smart Rural Transportation Planning and Optimization System

A beginner-friendly web prototype for rural transportation planning.

### Initial modules
1. Home dashboard
2. Passenger login with a simple NLP-style intent helper (planned)
3. Passenger route search and service requests (planned)
4. AI demand analysis and recommendations (planned)
5. Admin request review and schedule management (planned)

### Run locally
1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` with the Live Server extension.

This first version is a frontend scaffold. Login, shared passenger/admin requests, persistent storage, live bus tracking and real AI predictions are not yet connected.
